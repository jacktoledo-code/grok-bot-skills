# Grok Bot Skills

Skills and bots I built with Grok Bot and use in real life, shared in a privacy-safe form. Each skill is a plain `SKILL.md` an assistant can follow. Personal details stay out: no names, amounts, account numbers, or links to private folders.

## How to use a skill

1. Open the skill folder and read `SKILL.md`.
2. In Grok Bot, add that file as a skill. Any agent that reads `SKILL.md` can use it the same way.
3. Connect only what that skill asks for. You stay in charge of sending mail and signing in.
